# Contributing

Suggest a concrete demo through an issue or pull request. Include the original public source, creator, date, visible output and a short description of the task. A complete prompt is welcome but optional.

Include every qualifying demonstration. Merge reposts of the same work, preserve the creator’s labels and comparison conditions, and avoid adding launch speculation, account-usage screenshots or unrelated model demonstrations as cases. Do not invent inputs, scores or results.

Update the English README, all ten translations and both case indexes together. Keep stable case anchors, source/author links, type, date and media links aligned. Third-party work retains its original rights; provide attribution and honor correction/removal requests.
