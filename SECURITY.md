# Security

This repository publishes curated documentation and links to third-party demonstrations. It does not ship a service, SDK, executable examples or API credentials.

Report a broken, misleading or unsafe public link through a source-correction issue. Include the affected case and URL, without opening or uploading a suspicious payload. External services and linked projects manage their own security reports.

Never include secrets or personal information in a public issue. If a contribution exposes a credential, the credential owner should revoke it immediately; removing it from the current file does not remove earlier Git history. Maintainers can remove unsafe links or content after review.
